# KutemuKan

Lost and Found Kampus untuk komunitas Unindrabase (UNINDRA).
Aplikasi Flutter dengan backend Supabase (database dan login pada proyek mySika, tabel berawalan lf_) dan penyimpanan foto di Cloudflare R2 lewat endpoint unggah di VPS.

Fitur: papan barang hilang dan temuan, moderasi admin, kontak WhatsApp terlindungi, kotak masuk notifikasi dengan pencocokan temuan otomatis, dan perancah token perangkat untuk push FCM.

Build APK berjalan di GitHub Actions (build-apk.yml), hasil terbit sebagai Release build-N.
